## الملف اللي ترفعه

- الملف: `app-release.aab` (يتبنى من GitHub Actions لما تضيف مفتاح الرفع، شوف تحت).
- **Play App Signing:** خلّه مفعل (قوقل تحفظ مفتاح التوقيع، وأنت ترفع بمفتاح الرفع).
- بعد ما تفعّل Play App Signing، من (App integrity → App signing) انسخ بصمتين مفتاح قوقل: SHA-1 وSHA-256:
  1. أضفهم في Firebase Console ← Project settings ← تطبيق Android ← Add fingerprint (عشان دخول قوقل يشتغل في نسخة المتجر).
  2. أرسل لي SHA-256 عشان أضيفها لملف الروابط (`site/.well-known/assetlinks.json`)، وروابط الدعوة تفتح اللعبة مباشرة.

## مفتاح الرفع (upload key)

النسخ التجريبية الحالية موقعة بمفتاح تجربة. للمتجر نحتاج مفتاح رفع خاص ومحفوظ في GitHub Secrets:
`UPLOAD_KEYSTORE` (الملف بصيغة base64) و`UPLOAD_KEYSTORE_PASSWORD` و`UPLOAD_KEY_ALIAS` و`UPLOAD_KEY_PASSWORD`.
لما تكون جاهز للنشر، قل لي وأجهزه لك.
