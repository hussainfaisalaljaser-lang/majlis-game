# صوت الراوي

جمل الراوي السعودي (صوت «عبدالرحمن» من مكتبة ElevenLabs، رقمه `KfYUTAF49N2CPU3iKuMi`)،
مولّدة بـ ElevenLabs (نموذج eleven_v3) وقت اشتراك مدفوع يسمح بالاستخدام التجاري.
النصوص في `tools/voice/lines.json`، والسكربت `tools/voice/eleven.py`، ويشتغل من GitHub Actions
(workflow اسمه Narrator voice). اسم كل ملف هو مفتاح الجملة، مثل `gov_passed.mp3`.
الترحيب (`intro.mp3`) اخترناه من أكثر من محاولة.
